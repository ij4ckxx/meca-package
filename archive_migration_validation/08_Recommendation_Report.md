## Why zero journal-configuration recommendations

The rule requires ≥80% of a journal's articles to have `missing_metadata` (Recovery Rules RR-003/006/007 — reviewer identity, round attribution, optional XML sections). None of those three fired anywhere in this 37-article corpus, so there is no real evidence to recommend on. This is the intended behavior, not a gap: "never invent recommendations" means an unmet rule stays silent.

## Thresholds used (all documented in `recommendation_engine.py`)

| Rule | Threshold |

| Recovery Rule confidence upgrade | ≥10 occurrences, zero failure-correlated articles, not a significant-deficiency rule |
