# Recovery Matrix

Every exception-raising site in the reachable pipeline (extraction → transform → generators → packaging — the modules the real batch pipeline actually exercises; `input/`, `orchestrator/`, `retry/`, `registry/` beyond the DOI registry are not wired into production today and are out of scope), and the decision made for each.

| Site | Exception | Decision | Why |
|---|---|---|---|
| `extraction/xml_loader.py` (`_read_file`) | `SourceUnavailableError` | **Keep fatal** | File genuinely unreadable — nothing downstream is possible. |
| `extraction/xml_loader.py` (`_parse_tree`) | `SourceXmlMalformedError` | **Keep fatal** | Not well-formed / rejected by safe-parsing (entity/external-reference attack pattern) — recovering here means guessing at broken or unsafe XML. |
| `extraction/round_resolver.py` (missing/malformed `vocab-identifier` or `article-version-type`, per element) | `RoundResolutionError` | **Recover — skip the element** | One malformed `<article-version>` doesn't invalidate the others; skipping it and continuing is the same as the pre-existing "no round metadata at all" case, already treated as non-fatal. |
| `extraction/round_resolver.py` (duplicate `sequence_number`, **same** label) | `RoundResolutionError` | **Recover — deduplicate** | Real evidence (`bcj-2025-3400`, 34 identical-label duplicates with distinct timestamps) shows this is a repeated-autosave artifact, not a genuine second round. Collapsing identical entries removes redundancy without inventing an ordering. |
| `extraction/round_resolver.py` (duplicate `sequence_number`, **conflicting** labels) | `RoundResolutionError` | **Keep fatal** | A genuine, unresolvable ordering ambiguity (ADR-013) — guessing which label is "real" would fabricate provenance. |
| `extraction/file_resolver.py` (no physical file match, category = `manuscript`) | `FileReferenceMissingError` | **Keep fatal** | A package with no manuscript is not "the best possible package" — it's an empty shell. |
| `extraction/file_resolver.py` (no physical file match, any other category) | `FileReferenceMissingError` | **Recover — skip the entry** | The single highest-impact change: a missing supplementary/administrative file no longer discards an otherwise-complete package (real evidence: 6 of the corpus's 7 original failures were exactly this, each losing 5–29 correctly-resolved files over one gap). |
| `extraction/file_resolver.py` (tier-3 tolerance match) | *(was a latent bug, not an exception)* | **Fixed + now warned** | The tolerance tier already existed and was already silently used for near-matches; found and fixed a real comparison bug (`declared_name` vs `declared_stem`) that made a documented, intended tolerance case never actually work, and made every non-exact match surface a warning instead of resolving invisibly. |
| `generators/base.py` (`_generate` raises anything unclassified) | `GeneratorInvariantError` | **Keep fatal — ENGINE_DEFECT** | By definition an unclassified failure in already-validated input — a code defect, not recoverable data. |
| `generators/article_xml/generator.py` (`_build_doi`, no source DOI value) | `MissingDoiError` | **Keep fatal** | DOI is load-bearing identity for the whole package; inventing one risks a real collision. No safe derivation exists. |
| `generators/article_xml/generator.py` (`_add_license`, recognized License Type with no configured template) | `LicenseMappingError` | **Recover — omit `<license>`, warn** | A config completeness gap, not a data problem; the package is already correct without a license block for the (already-tolerated) non-CC-BY case — the same recovery now applies here. |
| `generators/reviews_xml/generator.py`, `transfer_xml/generator.py`, `manifest_xml/generator.py`, `raw_xml/xslt_generator.py`, `packaging/document_reader.py` (`_require_uri`, unregistered namespace prefix) | `GeneratorInvariantError` | **Keep fatal — ENGINE_DEFECT** | A config completeness gap that would affect every article identically — correct XML cannot be produced without the right namespace URI. Never observed in this corpus's live config. |
| `generators/reviews_xml/review_builder.py` (`_require_reviewer_identity`, has recommendation but no name/email) | `ReviewDataIntegrityError` | **Recover — keep content, omit identity, warn** | The review content itself is real, source-derived data; only attribution is missing. Discarding real content over a missing name is disproportionate, and anonymous-identity review items are already a tolerated shape elsewhere in this exact schema. |
| `generators/xml/builder.py`, `generators/raw_xml/xslt_transform.py` (serialization/XSLT failure) | `XmlSerializationError` | **Keep fatal — ENGINE_DEFECT** | A code/library-level failure (bad encoding name, XSLT engine error) — not a data-quality condition to recover from. |
| `generators/raw_xml/xslt_transform.py` (source XML fails to re-parse) | `SourceXmlMalformedError` | **Keep fatal** | Defense-in-depth only; the same bytes already parsed successfully upstream — if this ever fires it indicates a parser inconsistency worth investigating as its own defect, not a data issue to paper over. |
| `packaging/zip_builder.py` (unrecognized compression name) | `PackageAssemblyError` | **Keep fatal — ENGINE_DEFECT** | Configuration mistake, identical for every article in the run. |
| `packaging/asset_copy.py` (source file missing after resolution) | `PackageAssemblyError` | **Keep fatal — ENGINE_DEFECT** | File resolution already confirmed the file existed; disappearing between resolution and copy is an environment/race condition, not a data issue. |
| `packaging/asset_copy.py` (destination collision, `overwrite_policy="fail"`) | `PackageAssemblyError` | **Keep fatal** | Two entries claiming the identical output path is a genuine naming conflict; silently renaming one risks corrupting traceability. Never observed in this corpus. |
| `packaging/asset_copy.py` (post-copy checksum/size mismatch) | `PackageAssemblyError` (retryable) | **Unchanged — already transient-classified** | Environmental corruption, already correctly marked retryable by the existing exception hierarchy. |
| `packaging/builder.py` (`_resolve_packaged_files`, manifest references an href with no resolved file) | `PackageAssemblyError` | **Keep fatal — ENGINE_DEFECT** | Internal inconsistency between manifest generation and file resolution — if this ever fires, the two disagree with each other, which is a code defect. |
| `packaging/builder.py` (`_reserve_doi`, DOI already reserved) | `DoiCollisionError` | **Keep fatal** | A genuine cross-article collision (ADR-015); auto-resolving by picking a "winner" is an editorial/business decision, not something to guess silently. |
| `model/article.py`, `model/serialization.py` (`ArticleModelBuilder` invariants, `from_dict` schema version) | `ModelBuildError` | **Keep fatal — ENGINE_DEFECT** | Pure code-invariant assertions (write-once field violated, required field missing, unsupported schema version) — a defect in the code, never triggerable by source data alone. |
| `transform/coordinator.py` (`_reconcile_file_entry_round_labels`, resolved-count mismatch) | Was a bare `ValueError` | **Fixed to raise `ModelBuildError` — ENGINE_DEFECT** | Same category as the `ArticleModelBuilder` invariants above; now correctly a typed `MecaEngineError` per the exception hierarchy's own documented contract ("every exception must be a subclass of `MecaEngineError`"), and reclassified accordingly. |

## Net effect on this corpus

Every one of the 7 packages that failed in the prior validation round now generates. **Zero** packages in this 37-package corpus hit a still-fatal condition — `FAILED_ENGINE` and `FAILED_FATAL` both occurred 0 times in the end-to-end run (see `03_End_to_End_Batch_Summary.md`). The classification above remains in place for whatever future data does exercise those paths.
